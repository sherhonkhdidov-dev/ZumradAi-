# Zumrad AI Code & Design Starter Library

Studio sahifasi `/studio.html` da 4 ta to‘liq preview qilinadigan starter beradi. Har bir eksport `index.html`, `styles.css`, `app.js`, `README.md` fayllarini o‘z ichiga oladi.

## Template inventory

- **Portfolio:** hero, project cards, about, contact sections; responsive layout.
- **School dashboard:** metrics, activity feed, weekly chart, add-task interaction.
- **Online shop:** product catalog, cart count interaction, product cards.
- **SaaS dashboard:** KPI cards, revenue chart, recent transactions, CSV report export.

## Dataset v12

`data/professional_code_design_v12.jsonl` contains original learning examples about Python, JavaScript, HTML/CSS, React, SQL, API validation, testing, security, responsive design, and accessibility. `benchmarks/code_design_benchmark_v12.jsonl` is kept outside the training directory to avoid accidental train/eval leakage.

This corpus is a starter corpus written for this project; it is not a substitute for a large, carefully licensed, deduplicated professional code corpus. Model outputs still need human review and real tests.
