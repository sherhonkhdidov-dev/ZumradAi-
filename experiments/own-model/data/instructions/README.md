# Instruction dataset

Put UTF-8 `.jsonl` files here. One JSON object per line, e.g.:

```json
{"prompt":"Python da salom chiqar","response":"print('Salom')"}
{"messages":[{"role":"user","content":"Salom"},{"role":"assistant","content":"Salom! Qanday yordam beray?"}]}
```

Use only data you created or have permission to train on. Remove private data, credentials, phone numbers and personal records. Avoid copying copyrighted datasets without a license. Keep separate train/validation examples for serious evaluation.
